# Wordle (Python)

## Overview

A command-line implementation of the popular Wordle game built in Python. Players have six attempts to guess a randomly selected five-letter word while receiving feedback after every guess.

---

## Features

- Random word selection
- Six attempts
- Duplicate letter handling
- Input validation
- Colored terminal feedback
- Replayable gameplay

---

## Technologies Used

- Python
